## 📦 Components List

### 🔧 Electronics & Controllers
- Raspberry Pi 4 (or Raspberry Pi 3B+ compatible)
- Arduino Uno
- L298N Motor Driver Module
- HC-SR04 Ultrasonic Sensor (1–2 units)
- Pi Camera Module / USB Webcam
- DC Gear Motors (2 or 4)
- Motor Chassis / Rover Base

### 🔋 Power & Connectivity
- Li-ion Battery Pack / Power Bank
- Jumper Wires (Male–Male, Male–Female)
- DC Power Switch (optional)
- Breadboard (optional)
- Micro USB / Type-C Cable (for Pi)

### 📡 Communication & Storage
- USB Cable (Arduino ↔ Raspberry Pi)
- SD Card (32GB recommended)
- Wi-Fi Dongle / Built-in Wi-Fi

### ⚙️ Mechanical & Mounting
- Robot Chassis Frame
- Wheels + Couplers
- Screws, Nuts, Bolts, Spacers
- Camera Mount / Bracket
- Ultrasonic Sensor Holder
